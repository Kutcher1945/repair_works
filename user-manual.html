Система управления ремонтными работами

Версия 1.0, 2026 Для всех пользователей

01Обзор системы

Ремонтные работы — информационная система для регистрации, отслеживания и контроля дорожно-ремонтных работ. Система позволяет организациям-заказчикам подавать заявки на проведение ремонтных работ, а сотрудникам ЦОДД — рассматривать их и управлять жизненным циклом каждой заявки.

Регистрация заявок

Создание заявок с описанием работ, геолокацией, сроками и прикреплёнными документами.

Отслеживание статусов

Прозрачный жизненный цикл заявки от черновика до завершения с историей изменений.

Карта работ

Интерактивная карта с нанесёнными объектами активных и завершённых ремонтных работ.

Документооборот

Хранение договоров, актов выполненных работ, доп. соглашений и фотоматериалов.

Уведомления

Автоматические уведомления при изменении статуса или поступлении новых заявок.

Отчётность

Сводные данные по заявкам с фильтрацией по статусу, срокам и просроченности.

02Вход в систему

Доступ к системе осуществляется через браузер. На стартовой странице необходимо ввести учётные данные.

  1. Откройте адрес системы в браузере.
  2. Введите ваш email и пароль в соответствующие поля.
  3. Нажмите кнопку «Войти».
  4. После успешной аутентификации вы будете перенаправлены на главную страницу.
ℹ

Если у вас нет учётных данных, обратитесь к администратору системы. Самостоятельная регистрация не предусмотрена.

⚠

Сессия остаётся активной до явного выхода из системы. При работе на общем компьютере всегда завершайте сессию через кнопку «Выйти» в нижней части боковой панели.

03Интерфейс

Интерфейс состоит из трёх основных зон: боковой панели навигации, заголовка и рабочей области.

Боковая панель

Боковая панель расположена слева и содержит основное навигационное меню. Она может быть свёрнута до иконок — для этого нажмите на кнопку-стрелку, которая появляется на правом крае панели при наведении. Состояние (свёрнута/развёрнута) сохраняется между сессиями.

В нижней части боковой панели отображается:

  • Имя и email текущего пользователя
  • Название организации
  • Кнопка выхода из системы

04Главная страница

Главная страница предоставляет моментальный срез текущего состояния работ и содержит приветственный баннер, статистику и таблицу последних заявок.

Карточки статистики

Активных

На проверке

Заявки, ожидающие рассмотрения ЦОДД

Завершено

Успешно закрытые заявки

Последние заявки

Таблица под карточками отображает 5 самых последних заявок с полями: номер, наименование, организация, статус и дата создания. Клик по строке открывает карточку заявки.

Кнопка «Новая заявка»

Кнопка «Новая заявка» в правом углу приветственного баннера мгновенно открывает форму создания заявки. Это самый быстрый способ начать работу.

05Список заявок

Раздел «Заявки» — основное рабочее пространство. Здесь отображаются все заявки, доступные текущему пользователю, с расширенными возможностями фильтрации и сортировки.

Вкладки

Список разделён на вкладки по смысловым группам:

Вкладка Содержимое
ВсеВсе активные заявки (кроме удалённых)
ВниманиеПросроченные или истекающие заявки, требующие немедленного реагирования
ИстекаютЗаявки, у которых до планового окончания осталось мало времени
ПросроченныеЗаявки, у которых плановая дата окончания уже прошла
ЗавершённыеЗаявки со статусом «Завершён»
УдалённыеМягко удалённые заявки (доступны для восстановления)

Фильтры и поиск

Над таблицей расположена панель фильтров:

  • Строка поиска — ищет по наименованию, адресу, организации и участку дороги
  • Статус — выпадающий список для фильтрации по одному из статусов
  • Район — выпадающий список для фильтрации по административному району
  • Дата — диапазон дат начала работ (от/до)

Дополнительная фильтрация доступна непосредственно в заголовках столбцов таблицы: можно вводить текст или выбирать значения для фильтрации по каждому столбцу отдельно.

Предпросмотр заявки

При наведении курсора на строку таблицы появляется всплывающая карточка с ключевыми данными заявки: статус, заголовок, адрес, даты, подрядчик, количество оставшихся или просроченных дней, а также превью до 3 фотографий (загружаются автоматически).

Действия над заявкой

В конце каждой строки есть кнопка меню (⋯), которая открывает контекстное меню с доступными действиями:

  • Просмотр — перейти на страницу просмотра заявки
  • Редактировать — перейти на форму редактирования
  • Удалить — мягкое удаление (заявка перемещается во вкладку «Удалённые»)
  • Восстановить — доступно для удалённых заявок
ℹ

Удаление в системе является мягким (soft delete). Заявка не уничтожается безвозвратно — её всегда можно восстановить из вкладки «Удалённые».

Пагинация

В нижней части таблицы расположены кнопки страниц и переключатель количества записей на странице: 10 20 50 записей.

06Создание заявки

Форма создания открывается по кнопке «Новая заявка» (главная страница или кнопка в разделе «Заявки»). Заявка сохраняется в статусе Черновик и не отправляется на проверку до явного изменения статуса.

Разделы формы

2. Подрядчик

Поле «Подрядчик» — это умный автодополнитель (combobox). При вводе названия система выполняет поиск по реестру подрядчиков и предлагает совпадающие варианты. При выборе подрядчика из списка поле «Телефон» заполняется автоматически из сохранённых данных.

ℹ

При сохранении заявки с новым подрядчиком (которого нет в реестре) его данные автоматически добавляются в справочник для использования в будущих заявках.

3. Сроки проведения работ

Начало
Плановая дата начала работ *
Окончание

4. Ограничение движения

Переключатель «Ограничение движения» указывает, будут ли работы сопровождаться закрытием или сужением проезжей части. При активации появляется текстовое поле для описания характера ограничений.

5. Геолокация объекта

Интерактивный инструмент рисования на карте позволяет обозначить точное местоположение и контур объекта. Поддерживаются следующие типы геометрии:

  • Точка — для точечных объектов
  • Линия — для участков дороги
  • Полигон — для площадных объектов

Нарисованную геометрию можно редактировать и удалять. Указание геолокации делает заявку видимой на карте после её активации.

6. Документы

К заявке можно прикрепить файлы следующих типов:

Тип документаОписание
ДоговорОсновной договор на проведение работ
Доп. соглашениеДополнительное соглашение к договору
Акт выполненных работАкт приёмки завершённых работ
Документ о продленииОснование для изменения сроков

Поддерживаемые форматы: PDF, DOCX, XLS, XLSX, JPG, PNG. Файлы можно удалять до сохранения.

7. Фотографии «До начала работ»

При создании заявки можно загрузить фотографии объекта до начала ремонта. Фотографии отображаются в виде превью с возможностью удаления. После сохранения заявки дополнительные фазы фотографий (в процессе, после завершения) добавляются на странице редактирования.

Сохранение формы

  1. Заполните обязательные поля (помечены звёздочкой).
  2. Нажмите кнопку «Сохранить черновик» для сохранения без отправки.
  3. Или нажмите «Подать на проверку» для немедленной отправки в ЦОДД.
⚠

При попытке покинуть страницу с несохранёнными изменениями система отобразит предупреждение. Убедитесь, что сохранили данные перед переходом.

07Просмотр заявки

Страница просмотра открывается по клику на строку таблицы или пункт «Просмотр» в контекстном меню. Страница доступна только для чтения и содержит всю информацию по заявке.

Основные данные

Статус, наименование, организация, район, адрес, участок дороги, сроки, информация об ограничении движения, подрядчик.

Документы

Список прикреплённых документов с типом, именем и датой загрузки. Доступны для скачивания.

Фотографии

Три фазы: «До начала работ», «В процессе», «После завершения». Фото открываются в лайтбоксе по клику.

История статусов

Хронологический журнал всех переходов статусов: кто, когда и с каким комментарием изменил статус.

Комментарии

Обмен сообщениями между заказчиком и ЦОДД в рамках конкретной заявки.

Карта объекта

Встроенный виджет карты с нанесённой геометрией объекта (если указана при создании).

Изменение статуса

На странице просмотра (для авторизованных пользователей) доступны кнопки смены статуса, соответствующие допустимым переходам для текущего состояния заявки. Подробнее — в разделе «Жизненный цикл».

08Редактирование заявки

Форма редактирования имеет ту же структуру, что и форма создания, но содержит предзаполненные данные из существующей заявки.

Работа с документами

На вкладке редактирования отображаются уже прикреплённые документы. Рядом с каждым документом есть кнопка удаления — она удаляет файл немедленно (после подтверждения) и не требует сохранения формы. Новые файлы загружаются через зону перетаскивания и применяются при сохранении формы.

Работа с фотографиями

При редактировании доступны три вкладки фотографий:

  • До начала работ — фото до начала ремонта
  • В процессе — фото хода работ
  • После завершения — финальные фото

Существующие фото отображаются с превью и кнопкой удаления. Новые загружаются через ту же зону загрузки.

Запрос на продление сроков

Если требуется изменить плановую дату окончания работ, заказчик может подать запрос на продление. После рассмотрения администратором дата окончания обновляется в системе.

⚠

Редактирование заявки доступно, пока она не переведена в статус Завершён или Аннулирован.

09Жизненный цикл заявки

Каждая заявка проходит через строго определённые статусы. Переходы между статусами контролируются системой и зависят от роли пользователя.

Статусы

Статус Значение Кто устанавливает
Черновик Заявка создана, но ещё не подана. Доступна для редактирования. Создаётся автоматически
На проверке Заявка подана в ЦОДД для рассмотрения. Ожидает решения. Заказчик
На доработке ЦОДД вернул заявку с замечаниями. Требуется исправление и повторная подача. Администратор ЦОДД
Активный ремонт Заявка одобрена. Работы выполняются. Объект отображается на карте. Администратор ЦОДД
Завершён Работы выполнены и приняты. Заявка закрыта. Администратор ЦОДД
Аннулирован Заявка отменена на любом этапе. Объект снимается с карты. Заказчик или Администратор

Схема переходов

Черновик Создана, не подана
→
На проверке Подана в ЦОДД
→
Активный ремонт Одобрена ЦОДД
На доработке Возврат с замечаниями
→
Завершён Работы приняты

Из любого статуса (кроме «Завершён») возможен переход в Аннулирован. Из «На доработке» можно повторно подать заявку в «На проверке».

Уведомления при смене статуса

  • При переводе в На проверке — уведомление всем администраторам ЦОДД
  • При любом другом изменении статуса — уведомление автору заявки

10Карта

Раздел «Карта» предоставляет интерактивную визуализацию всех ремонтных объектов с нанесённой геолокацией.

Отображаемые объекты

На карте отображаются заявки, для которых указана геолокация (точка, линия или полигон). Удалённые заявки не отображаются. Для каждого объекта цвет маркера соответствует статусу:

Черновик На проверке На доработке Активный ремонт Завершён Аннулирован

Фильтрация по статусу

В верхней части страницы карты расположен фильтр по статусу — позволяет быстро оставить на карте только объекты нужного статуса (например, только активные работы).

Всплывающие подсказки

Клик по маркеру объекта открывает попап с кратким описанием: наименование заявки, адрес, статус и ссылка для перехода к полной карточке.

Статистика

На странице карты отображается сводная информация: общее количество заявок с геолокацией и количество объектов, видимых в текущем фильтре.

11Отчёты

Раздел «Отчёты» предоставляет аналитический срез по всем заявкам системы с возможностью фильтрации и сортировки.

Доступные фильтры

  • По статусу
  • По просроченности (просроченные / в срок)
  • По периоду (плановые даты начала и окончания)
  • По организации
  • По району

Данные таблицы

Для каждой заявки в отчёте отображаются:

  • Наименование и статус
  • Организация и район
  • Плановые даты начала и окончания
  • Просрочка (в днях) или оставшиеся дни
  • Дата создания заявки
ℹ

Отчёты отображают данные в режиме реального времени — информация актуальна на момент открытия страницы.

12Уведомления

Система автоматически информирует пользователей о важных событиях через колокольчик уведомлений в правом верхнем углу интерфейса.

Когда приходят уведомления

  • Заявка переведена в статус «На проверке» — уведомление получают все администраторы
  • Статус заявки изменён — уведомление получает автор заявки

Работа с уведомлениями

Счётчик непрочитанных

Красный бейдж на иконке показывает количество непрочитанных уведомлений (до 9+). Обновляется каждые 30 секунд.

Список уведомлений

Клик по колокольчику открывает панель со списком последних уведомлений. Непрочитанные выделены синим фоном.

Отметка как прочитанное

Клик по уведомлению отмечает его как прочитанное и (если привязано к заявке) переходит на страницу этой заявки. Кнопка «Прочитать все» сбрасывает счётчик сразу.

13Управление пользователями

🔒

Данный раздел доступен только администраторам. Сотрудникам-заказчикам раздел не виден.

Раздел «Пользователи» предоставляет администратору полный список учётных записей с возможностью поиска, фильтрации и управления.

Список пользователей

Таблица отображает для каждого пользователя:

  • Имя, фамилию и email
  • Номер телефона
  • Название организации
  • Роль в системе
  • Статус аккаунта (активен / заблокирован)
  • Дату регистрации

Поиск и фильтрация

  • Поиск по имени, фамилии, email или организации
  • Фильтр по роли: Администратор, Сотрудник

Действия

  • Активировать / Заблокировать — переключает доступность аккаунта
  • Создать пользователя — форма добавления нового аккаунта
  • Редактировать — изменение данных существующего пользователя
⚠

Заблокированный пользователь не сможет войти в систему. Все его заявки при этом сохраняются.

15Роли и доступ

В системе предусмотрено две основные роли с разными правами доступа.

Сотрудник (Заказчик)

  • Создание заявок
  • Просмотр своих заявок
  • Редактирование черновиков
  • Подача заявки на проверку
  • Загрузка документов и фото
  • Запрос продления сроков
  • Аннулирование своих заявок
  • Просмотр карты
  • Просмотр своих уведомлений

Администратор (ЦОДД)

  • Всё, что доступно сотруднику
  • Просмотр всех поданных заявок
  • Одобрение и перевод в «Активный»
  • Возврат на доработку с комментарием
  • Завершение и аннулирование любой заявки
  • Управление пользователями
  • Просмотр всех уведомлений
